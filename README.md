# e卷通 第14题 自动阅卷工具

针对 [e卷通](https://ejt.xkw.com) 平台的主观题（第14题）自动阅卷辅助脚本。  
流程：**Selenium 截图 → 图像预处理 → OCR 识别手写答案 → 自动评分 → 弹窗显示结果 → 循环下一题**

---

## 文件说明

| 文件 | 说明 |
|------|------|
| `auto_grade_q14.py` | 主脚本：完整自动化流程，包含浏览器控制、OCR、评分、弹窗 UI |
| `grade_q14.py` | 评分核心模块：可单独运行测试，也可被其他脚本 `import` |

---

## 功能特性

- **自动截图**：优先 CSS 精确定位答题区域，失败时回退到坐标裁剪
- **图像预处理**：CLAHE 对比度增强、去除答题纸横线、二值化、笔画加粗，提升 OCR 准确率
- **分区识别**：自动将答卷按空白行切分为 3 段分别 OCR，比整图识别更准确
- **双 OCR 方案**：
  - **方案 A（推荐）**：百度云"手写文字识别" API，手写中文识别率最高
  - **方案 B（本地）**：PaddleOCR，无需网络，但手写识别有限
- **智能评分**：关键词多层匹配（精确 / 模糊），支持同义表达
- **弹窗 UI**：评分结果弹窗，一键调整分值，自动在网页填分并切换下一题
- **循环模式**：关闭弹窗后自动截图下一题，支持 Ctrl+C 退出

## 快速开始

### 1. 安装依赖

```bash
pip install selenium pillow opencv-python requests
```

如需使用 PaddleOCR（方案 B）：

```bash
pip install paddlepaddle paddleocr
```

> 还需安装与 Chrome 版本匹配的 [ChromeDriver](https://chromedriver.chromium.org/)

### 2. 配置 API Key（推荐）

在 `auto_grade_q14.py` 顶部找到配置区，填入你的百度云密钥：

```python
BAIDU_API_KEY    = "你的 API Key"
BAIDU_SECRET_KEY = "你的 Secret Key"
```

> 申请地址：[百度智能云 - 文字识别](https://console.bce.baidu.com/) → 创建应用 → 获取密钥  
> 免费额度：每天 500 次手写识别

### 3. 修改路径配置

```python
OUTPUT_DIR = r"C:\你的路径\screenshots"   # 截图保存目录
```

### 4. 校准截图区域

首次运行时先查看 `raw_fullpage.png`（整页截图），用画图工具量出答案区域坐标，填入：

```python
CROP_BOX = (left, top, right, bottom)    # 像素坐标
```

### 5. 运行

```bash
python auto_grade_q14.py
```

脚本启动后：
1. 自动打开 Chrome 并跳转到 e卷通
2. 等待你登录并导航到第14题（默认等 60 秒，按回车可提前跳过）
3. 自动截图 → 识别 → 评分 → 弹出结果窗口
4. 在弹窗中确认/调整分值，点击「提交」后自动打分并进入下一题

## 注意事项

- **API 密钥安全**：请勿将 `BAIDU_API_KEY` / `BAIDU_SECRET_KEY` 提交到公开仓库，建议使用环境变量管理
- **答题纸格式**：不同版本答题纸的布局可能不同，需相应调整 `CROP_BOX`
- **OCR 准确率**：手写识别存在误差，建议对照弹窗中的 OCR 原文核实后再提交分数
- **仅供辅助**：本工具为阅卷辅助，最终评分请由教师审核确认
